# Technician Mobile Scaffold

This is the native Expo Router application for Command Centre field technicians. It was generated with `create-expo-app@latest` using the explicit `default@sdk-57` template.

## Resolved native versions

- Expo SDK: ~57.0.4
- React Native: 0.86.0
- React: 19.2.3

## Local commands

- `pnpm start`
- `pnpm ios`
- `pnpm android`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm test`

Copy `.env.example` to `.env.local` for local configuration. Never add OAuth client secrets to this application.
