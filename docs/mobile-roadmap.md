# Command Centre Mobile Roadmap

The first `/mobile` MVP is mock/API-ready only. It is built for real-phone review without MSP Central writeback, live tracking, manual dispatch records, push notifications, full offline mode, or an asset/device view.

## MVP scaffolds

These field-work capture areas exist in the MVP as local/mock scaffolds only:

- Attachments/photos: evidence can be staged locally with a mock pending upload state.
- Customer sign-off: customer name, accepted checkbox, and signature text can be staged locally with a mock pending sync state.
- Parts used: part name, SKU, and quantity can be staged locally with a mock pending sync state.

Outlook Read Only jobs keep these scaffold actions disabled.

## Future phases

These items are intentionally deferred until the web mobile workflow is proven and the required APIs are available:

- Real MSP Central sync for attachments/photos, customer sign-off, parts used, work notes, status changes, completion, reassignments, and escalations.
- Push notifications for assigned jobs, schedule changes, SLA risk, and escalations.
- Full offline mode with offline sync and conflict handling.
- Native iOS and Android packaging.
